# 🛠️ C Projects
A collection of small C projects built to sharpen low-level programming skills, explore system concepts, and have fun along the way.

## Philosophy
> *"The best way to learn C is to write C."*

Each project in this repo is self-contained and focused on a specific concept — graphics, algorithms, data structures, simulations, and more. The goal is steady progress through practice, one project at a time.

## Projects

| Project | Description | Concepts |
|---|---|---|
| [wave-reflections](./wave-reflections) | Real-time wave propagation and reflection simulation | raylib, particle systems, trigonometry |
| [sorting-visualizer](./sorting-visualizer) | Step-by-step sorting algorithm visualizer with live bar rendering | raylib, algorithms, Fisher-Yates shuffle |

> More projects coming soon...

## Skills Being Developed
- Memory management & pointers
- Data structures (linked lists, trees, hash maps...)
- Algorithms (sorting, searching, graph traversal...)
- Graphics & simulations with raylib
- File I/O and system calls
- Bit manipulation

## Building Any Project
Each project has its own folder with a dedicated README. Navigate into it and follow the instructions there.

```bash
cd project-name
gcc main.c -o output -lm   # adjust flags per project
./output
```
